# DogSC 功能对照 · 0.4.4 Alpha

依据用户提供的完整演示录屏和原仓库建立需求，见 [VIDEO_STUDY.md](VIDEO_STUDY.md)。下表是实现范围；测试证据见 [VALIDATION.md](VALIDATION.md)，不表示全部设备和系统已验证。

| 功能 | 本版实现 | 差异或边界 |
|---|---|---|
| 小工具栏 → 录制条 → 完成卡片 → 编辑器 | 已实现，启动仅显示小窗，完成后选择保存或编辑 | Windows 原生布局与字体 |
| 显示器、窗口、区域 | gdigrab，30/60 FPS | 最小化/保护内容、多 DPI/多屏待补测；暂无 WGC/D3D 采集 |
| 系统声音、麦克风 | WASAPI 独立 WAV、设备选择、音量、混音预览/导出 | 长时间及不同设备同步待测 |
| 摄像头、视频设备 | DirectShow 独立采集；导入视频画中画 | 导入已测；物理摄像头/采集卡待测 |
| iPhone/iPad 原生有线采集 | 未实现 | DirectShow 入口不能替代 Apple 有线协议 |
| 暂停/继续、标记、备忘录、桌面图标 | 已实现；暂停区间不进入成片；窗口尝试排除采集 | 正常退出恢复图标；崩溃恢复、各后端排除效果待测 |
| 隐藏软件面板 | 录制前开关、记住选择；采集前隐藏窗口并等待桌面合成，结束/失败恢复；全局快捷键或托盘双击停止 | 实录首/中/末帧验证通过；托盘保留停止入口 |
| 时间线、缩略图、波形 | 主轨与缩放、3D、摄影机、叠加层效果轨 | 叠加层共用视觉轨，可从列表选择重叠效果 |
| 分割、裁剪、重排、变速 | 拖拽边缘/片段，0.25–4×，边界吸附 | 超长工程性能待测 |
| Q/W、局部恢复、恢复原片 | 已实现，剪辑重映射效果时间 | 局部恢复限同速且源时间顺序相同；不归档已删效果 |
| 撤销/重做、效果复制与参数粘贴 | 工程级历史最多 40 步，支持贴图粘贴 | 裁剪边缘可能重启动画阶段 |
| 自动/手动缩放 | 点击生成缩放段，位置/倍率/曲线可调 | 策略与曲线近似原版 |
| 3D 运镜、聚焦虚化 | XYZ 旋转、透视、相邻段过渡和焦点模糊 | WPF 合成；性能按场景实测 |
| 开场动画 | 多种样式、方向、时长与曲线 | 非原版精确物理参数 |
| 背景 | 纯色/渐变/网格/点阵/动态网格/图片/视频/Windows 壁纸 | 不捆绑原版壁纸资产 |
| 布局、外框、裁切 | 比例、位置、大小、圆角、描边、阴影、窗口/浏览器框和八柄裁切 | 基础外框，未含全部设备样机素材 |
| 独立光标 | 原生形状/热点、触控/隐藏、大小、平滑、闲置隐藏和时间偏移 | 原生形状已实录；高 DPI/自定义光标待补测 |
| 点击反馈 | 波纹等反馈，随缩放/布局变换 | 具体视觉细节有差异 |
| 摄像头画中画 | 蒙版、镜像、边框、阴影、内部平移/缩放、位置/大小动画 | 采集延时及硬件组合待测 |
| 模糊、贴图、柔化背景 | 源区域模糊、图片/剪贴板、背景层和底层模糊 | 复杂 3D 场景中的蒙版拖拽定位需完善，可用参数调整 |
| 场景预设 | 手动保存/应用，复制背景素材 | 保存全局样式/摄像头/音量；不复制时间线，不自动套用 |
| 预览 | 默认完整分辨率；原生视频表面、实时 2D/3D/模糊效果、混音和失焦暂停；后台解码兜底 | 编码支持与加速取决系统媒体组件/显卡，重度场景仍有性能边界 |
| 全屏剪辑/预览 | F11 全屏剪辑，F 全屏预览；播放、暂停、进度、控制条隐藏和窗口状态恢复 | 默认使用原画布分辨率，可手动选择清晰预览降低负载 |
| 界面主题 | 设置内即时切换黑底白字/白底黑字并保存，粗体保留 | 配色仅属于应用界面设置 |
| MP4 / M4A | 720p/1080p/1440p/4K/原画布，30/60；估算大小和取消保护 | 软件 x264 编码；4K60 已通过短片检查，无硬件编码选项 |
| 工程继续编辑 | `.menfan` v2、兼容 v1、相对引用和自动保存 | 素材需随文件夹迁移，无打包工程 |
| Windows 兼容 | 本轮 Windows 10 22H2 x64 实测 | Windows 11、不同显卡、长录制待验证 |
| 发布 | 自带 .NET 的便携 ZIP、构建脚本和 CI 配置 | 未上传 GitHub；无签名安装器/自动更新，暂为中文界面 |

后续重点为 Windows 11 与设备实测、长录制同步、多 DPI、GPU 采集与合成、复杂工程细节和发行体验。本版不能宣称与原版完全功能对等。
