# 工具栏与编辑器 · 0.4.4

启动显示 980×178 DIP 录制工具栏，大编辑器初始化但隐藏。录制时切换为 640×142 DIP 控制条，提供暂停、备忘录、标记、桌面图标和停止。完成卡片提供保存项目和进入编辑两条路径。

工具栏和编辑器顶部均提供“设置”。黑底白字模式窗口底色 `#000000`、面板 `#101010`、文字 `#FFFFFF`；白底黑字模式窗口底色 `#FFFFFF`、面板 `#F7F7F7`、文字 `#000000`。两种模式均为 Bold，时间线、控件、菜单、辅助窗口和受支持系统上的原生标题栏即时切换。选择保存在本机用户设置中，下次启动恢复。新录制/导入从无留白、无圆角的原始画面开始；只有用户主动修改后才显示背景等画面效果。

“全屏剪辑 F11”隐藏系统窗口边框并保留所有剪辑工具；“全屏预览”或 F 隐藏编辑面板，只显示同一合成画面。支持播放/暂停、进度拖动、逐帧，控制条闲置三秒后隐藏，鼠标移动重新显示。Esc 依次返回全屏剪辑/原窗口，并保留播放头。已最大化的窗口退出预览仍为最大化。默认选择完整分辨率，普通和全屏模式都保留原画布尺寸；清晰预览仍可手动选择。

编辑器为左模块、中央合成预览、右属性和底部多轨时间线。裁切模式显示源画面与八个边缘/角部手柄，完成后恢复合成预览。关闭编辑器返回工具栏并保留工程，关闭工具栏退出。

WPF 组件检查覆盖窗口切换、主题、预览、时间线左侧定位、静音和裁切状态。通过 RenderTargetBitmap 生成并检查截图，位于 `artifacts/ui-tests/recorder.png`、`editor.png`、`crop.png`。这些为应用渲染截图，并非完整桌面截图。


录制工具栏右下角新增“录制时隐藏面板”，录制前可切换并记住选择，倒计时/录制中禁用修改。开启后在开始采集前隐藏软件窗口，结束或启动失败后恢复。停止入口为 Ctrl+Alt+R 或双击托盘图标；不显示托盘菜单以避免面板进入录制。
